Setup

How to install

Gmail

Open this file in a browser → select the signature you want (click and drag across it) → copy (Ctrl/Cmd + C). Then in Gmail: Settings → See all settings → General → Signature → Create new → paste → Save changes at the bottom.

Apple Mail

Select and copy the rendered signature the same way, then Mail → Settings → Signatures → + and paste. Uncheck “Always match my default message font.”

Outlook (web & new Outlook)

Settings → Mail → Compose and reply → Email signature → paste the copied signature → Save.

Tip

Send yourself a test email first and check it on your phone — both variants are built with email-safe table layout and inline styles, so they hold up across clients.
